# MARINA × LAITEC

Персональное профессиональное портфолио Марины Малышевой, руководителя проектов LAITEC.

**Публичная страница:** https://mmalysheva22-create.github.io/marina-laitec-portfolio/

**Утверждённое ТЗ:** [DESIGN_SPEC.md](DESIGN_SPEC.md).

**QR-код:** [SVG](assets/marina-portfolio-qr.svg), ведущий на публичный сайт.

## Структура
- `index.html` — адаптивная страница, тёмно-синий и золотой стиль, портфолио и контакты.
- `assets/vtb_aerial_approved.webp` — выбранная пользователем аэросъёмка ВТБ.
- `assets/marina_hero_twilight_v4.webp` — вечерний архитектурный фон главного экрана.
- `Marina_Malysheva_LAITEC.vcf` — карточка контакта.
- `.github/workflows/pages.yml` — автоматическая публикация GitHub Pages.

## Актуальность кейса ВТБ
На сайте указаны **две реализованные системы управления освещением**. Модернизация спортивного света не обозначается как завершённая.

## Публикация
Любой коммит в `main` запускает GitHub Pages через GitHub Actions. Последний статус публикации проверяется в разделе **Actions**. Мобильная визуальная приёмка выполняется отдельно.

## Изображения
Фотографии объектов используются для иллюстрации портфолио. Право коммерческого использования пользовательских и сторонних снимков должно быть подтверждено правообладателем.
